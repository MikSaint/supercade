# Supercade flat-pack viewer

A 3D model of the Supercade cabinet built from the same numbers as the
printable plans. You can:

- **Switch size:** full size, kid height (8" lower) or half scale.
- **Take it apart:** *Built*, *Exploded* (the Spread slider sets how far) or
  *Flat-pack* (every part laid out on the cutting mat).
- **Add people for scale:** an adult (170 cm) and kids aged 8 and 5, using
  CC0 body meshes from Blender Studio's Human Base Meshes (see
  `people/LICENSE.txt`). The panel compares each person's elbow height with
  the control deck.
- **Try finishes:** cardboard, birch ply, walnut or paint (7 colours), with
  optional side-art stripes.
- **Read sizes:** hover any part for its size, and switch between inches and cm.

## Run it

No install or build step. Open `index.html` in a browser:

```sh
git clone https://github.com/MikSaint/supercade.git
cd supercade
open cardboard/viewer/index.html        # macOS
# xdg-open cardboard/viewer/index.html  # Linux
# start cardboard\viewer\index.html     # Windows
```

It loads Three.js r128 and the fonts from public CDNs, so the first open needs
an internet connection. If your browser blocks local files, serve the folder
instead:

```sh
cd cardboard/viewer && python3 -m http.server 8000
# then open http://localhost:8000
```

## Where the numbers come from

`data.js` is generated by `../generate.py`, alongside the PDFs. It holds the
side-panel profile, the panel lengths, the screen recess, shelf positions and
control layouts. `people.js` packs the body meshes so the page works straight
from disk. To
change the design, edit the generator and re-run `python3 generate.py`. The
viewer and the printable plans update together.
